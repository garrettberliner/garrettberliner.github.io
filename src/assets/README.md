## Replacing things

### Photos

Keep the same filename &amp; nothing else needs to change. If you rename, update the `<img src>` **&amp;
the `width`/`height` attributes** - those are there to stop the page from jumping around while the
image loads, so wrong numbers are worse than none.

`IMG_3456.jpg` is ~1.9 MB, which is large for a hero image. If you ever re-export it, aim for
under 400 KB at roughly 1600px on the long edge - the site will feel noticeably faster on mobile.

### PDFs

Add the new file here, then update **3 references** on the matching page (`resume/index.html` or
`cv/index.html`): the hero download button, the card download button, &amp; the `<iframe src>`. Also
update the "Last Updated" stat &amp; the `Last updated ...` line so the page doesn't lie.

The `download="Garrett_Berliner_Resume.pdf"` attribute controls the filename people get when they
save it - worth keeping clean regardless of what the file is called here.

### The social card

`og-card.png` must stay **exactly 1200×630** - that's what LinkedIn, Slack, iMessage, &amp; Twitter
expect. Anything else gets cropped badly.

It was generated by screenshotting a small standalone HTML template at that viewport size. To redo
it, build a 1200×630 page using the site's own tokens &amp; fonts, screenshot it, &amp; save it here.

### The favicon &amp; the site mark

`favicon.svg` is a hand-written SVG: three rainbow arcs (red / gold / green) rising *behind* a solid
peak, which are clipped by a `<mask>` so the peak genuinely occludes them. It's referenced as
`image/svg+xml`, so it scales to any size &amp; needs no PNG fallbacks for modern browsers.

The same shape is inlined as `<svg class="brand__mark">` in the header of all 7 pages &amp; drawn on
the OG card. **If you change the logo, change it in all 9 places** - the favicon, the 7 headers, &amp;
the OG card template. The mountain is `fill="currentColor"` so it flips ink colour between Trailhead
&amp; Downtown on its own; the arcs stay fixed brand colours in both.
